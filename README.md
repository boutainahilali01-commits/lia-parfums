# Lia Parfums

## Description
Lia Parfums est une application web développée avec Laravel pour la gestion et la vente de parfums en ligne.

## Fonctionnalités

### Client
- Affichage des parfums disponibles
- Ajout au panier
- Validation des commandes
- Suivi des commandes

### Administrateur
- Authentification sécurisée
- Ajout de produits
- Modification du stock
- Suppression de produits
- Gestion des commandes
- Changement du statut des commandes
- Tableau de bord avec statistiques

## Technologies utilisées
- Laravel
- PHP
- MySQL
- Blade
- HTML
- CSS
- JavaScript
